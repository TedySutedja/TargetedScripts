How do you offer websites with zero ongoing hosting fees?

We deploy lightweight static HTML/Tailwind CSS sites directly onto modern global CDN cloud platforms like GitHub Pages and Cloudflare. This completely eliminates expensive monthly web hosting server costs for standard business websites.

What tools do you use for process automation?

We specialize in Google Workspace automation (Google Apps Script, Google Sheets, Gmail), custom Python scripts, and n8n workflow integrations to automate manual email dispatch, report generation, and data syncing.

Targeted Scripts is based in Palmerston North, New Zealand. We work directly with local businesses and community organizations across Manawatu, Auckland, Wellington, and nationwide.
